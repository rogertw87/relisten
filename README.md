# 全球共修重聽

楊定一博士 2020～2026 全球線上共修的重聽進度表。標題下面的「2026 全球共修 ▾」可以切換年份，每一屆的打勾、心得、想再聽、重聽排程和印章冊分開記，標籤共用；也可以用 `#2023` 這樣的網址直接打開某一屆。2026「信任」照實際排：7/1 到 8/31 共 62 天，每天早上、中午、晚上各一段，週六另有 10 點和下午兩段補充、週日另有下午一段補充；其他年份先用預設格式（7/1 起 62 天，每天早、午、晚，週六日各一段補充），之後再照 App 裡的實際內容調整。聽完一段點一下就會打勾。

- 單一檔案的靜態網頁（`index.html`），不需要安裝或建置。
- 打勾、印章、獎勵、標籤和心得都存在瀏覽器的 localStorage；可以從「心得」分頁「匯出」成文字檔備份（心得和標籤都會匯出）。
- 雲端同步（可以不用）：按左上角「登入同步」或「進度」分頁的「用 Google 登入同步」，資料會存在自己 Google 雲端硬碟裡應用程式專用的隱藏資料夾（`drive.appdata` 權限），換手機、用電腦登入同一個帳號就會同步；做網頁的人看不到任何人的資料。每一筆資料記著修改時間，兩台裝置各改各的會合在一起，取消打勾也會同步。LINE 等 App 內建的瀏覽器不能登入 Google，會提示改用 Chrome 打開。
- 表格依共修說明排列，App 裡實際的段數如果不同，以 App 為準。
- 畫面最下面有四個分頁：
  - 清單：每天的早、午、晚。左上角可以切換「簡化」（三格並排，有標籤的格子上緣會有寫著標籤第一個字的小圓標）和「詳細」（每段一列，會寫出標籤和心得）；右上角「隱藏完成的練習」可以把聽完的那一段先藏起來。
  - 標籤：全部的標籤和每個標籤標在哪幾段；點某一段會跳回清單那一天。「編輯標籤」可以新增、改名、刪除。
  - 心得：每一天一張卡，分早上、中午、晚上列出心得；右上角可以「匯出」。
  - 進度：已聽段數、重聽排程（可以不設；設了開始日期後，可以選一天份用 1 到 7 天聽完）、顯示共修日期、「想再聽」清單，以及印章冊。
- 心得和標籤：點筆的圖示（簡化在每一天最右邊）、「心得」（詳細在每一列右邊）或點「第01天」，在視窗裡寫早、午、晚各段的心得，並在每一段下面選標籤。
- 想再聽：在心得視窗點「☆ 想再聽」，那一段的格子上方會出現一顆星星（詳細在名稱後面加一顆星），「進度」分頁會列出來，點一下跳回那一天。
- 每 7 天聽完會蓋一個印章，全部聽完再蓋「圓滿」；點印章可以寫下要給自己的獎勵。
- 右上角選單：「使用說明」用小圖解說各個功能；「主題」可選「淺色」（預設）、「夜間」（黑底、打勾變黃色）、「黑白」，記在各自的裝置；網站版另有「加到手機桌面」，`manifest.webmanifest` 和 `icons/` 是桌面圖示用的。
- `privacy.html`（隱私權政策）和 `terms.html`（使用條款）：Google 登入發布成正式版時需要的頁面，首頁最下面有連結。
