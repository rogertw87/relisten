# 全球共修重聽

楊定一博士 2020～2026 全球線上共修的重聽進度表。打開網站先到首頁，上面列出七屆，一屆一列（例如「2026 信任」），點一列就進到那一屆；在某一屆裡按左上角「‹ 首頁」回到首頁。每一屆的打勾、心得、想再聽、重聽排程和印章冊分開記，標籤共用；也可以用 `#2023` 這樣的網址直接打開某一屆。七屆的格子都照「全部生命」官方課程頁的清單排：2022～2026 各 62 天、2021 是 92 天、2020 是 37 天（每天早、晚）；早、午、晚算進度，問答、補充、下午等其他段落是虛線的補充格，不算進度。每一段會顯示官方課程頁上的題目（經全部生命團隊同意列出，頁尾有出處和官方連結）。聽完一段點一下就會打勾。

- 靜態網頁（`index.html`），不需要安裝或建置。各屆的題目另外放在 `titles-2020.json`～`titles-2026.json`，一屆一個檔；拿掉某個檔，那一屆就不顯示題目和出處，格子照常能用。
- 打勾、印章、獎勵、標籤和心得都存在瀏覽器的 localStorage；可以從「心得」分頁「匯出」成文字檔備份（心得和標籤都會匯出）。
- 雲端同步（可以不用）：在右上角「⋯」選單打開「雲端同步」，用 Google 登入，資料會存在自己 Google 雲端硬碟裡應用程式專用的隱藏資料夾（`drive.appdata` 權限），換手機、用電腦登入同一個帳號就會同步；做網頁的人看不到任何人的資料。每一筆資料記著修改時間，兩台裝置各改各的會合在一起，取消打勾也會同步。登入一小時後通行證會到期，之後點一下畫面就會自動重新連上並同步。LINE 等 App 內建的瀏覽器不能登入 Google，雲端同步的視窗會提示改用瀏覽器打開。
- 清單裡沒有天數編號的項目（開始前的說明、結語、穿插的示範等）沒有列入；實際內容以官方平台為準。
- 畫面最下面有五個分頁。首頁也有這一列：在首頁時第一顆是「首頁」，其他四顆會打開上次看的那一屆（還沒進過任何一屆就是最新一屆）；標籤、心得、進度三頁的最上面會寫現在看的是哪一屆。
  - 清單：每天的早、午、晚。左上角可以切換「簡化」（三格並排，有標籤的格子上緣會有寫著標籤第一個字的小圓標）和「詳細」（每段一列，會寫出標籤和心得）；右上角「隱藏完成的練習」可以把聽完的那一段先藏起來。
  - 標籤：全部的標籤和每個標籤標在哪幾段；點某一段會跳回清單那一天。「編輯標籤」可以新增、改名、刪除。
  - 搜尋：找各段的題目和自己寫的心得，七屆一起找（可以改成只找這一屆，或只找題目、只找心得），目前這一屆排最前面。多個詞用空白隔開表示都要有；不管標點、空白、英文大小寫和全形半形，「波羅密／波羅蜜」「瑜珈／瑜伽」當成同一個詞；也會比對「第幾天・哪一段」，所以打「問答」「下午 呼吸」「第41天」都找得到。點找到的那一段會換到那一屆、跳到清單裡那一天並框起來（點到心得會打開那一則）；那一段如果被「隱藏完成的練習」收起來，會先取消隱藏。搜尋只在自己的裝置上進行；第一次用會把其他屆的題目檔讀進來。
  - 心得：每一天一張卡，分早上、中午、晚上列出心得；右上角可以「匯出」。
  - 進度：已聽段數、重聽排程（可以不設；設了開始日期後，可以選一天份用 1 到 7 天聽完）、顯示共修日期、「想再聽」清單，以及印章冊。
- 心得和標籤：點筆的圖示（簡化在每一天最右邊）、「心得」（詳細在每一列右邊）或點「第01天」，在視窗裡寫早、午、晚各段的心得，並在每一段下面選標籤。
- 想再聽：在心得視窗點「☆ 想再聽」，那一段的格子上方會出現一顆星星（詳細在名稱後面加一顆星），「進度」分頁會列出來，點一下跳回那一天。
- 每 7 天聽完會蓋一個印章，全部聽完再蓋「圓滿」；點印章可以寫下要給自己的獎勵。
- 右上角選單：「使用說明」用小圖解說各個功能；「主題」有淺色（預設）、夜間、黑白、晨曦、森林、薰衣草、深海、夜空八種；「字的大小」可選「標準、大、特大」，整個網站的字一起放大；兩者都記在各自的裝置，不會跟著雲端同步；網站版另有「加到手機桌面」，`manifest.webmanifest` 和 `icons/` 是桌面圖示用的。
- `privacy.html`（隱私權政策）和 `terms.html`（使用條款）：Google 登入發布成正式版時需要的頁面，首頁最下面有連結。
