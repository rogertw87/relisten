# 信任重聽進度表

2026 全球線上共修「信任」的重聽進度表。7/1 到 8/31 共 62 天，每天早上、中午、晚上各一段，週末另有補充；聽完一段點一下就會打勾。

- 單一檔案的靜態網頁（`index.html`），不需要安裝或建置。
- 打勾、印章、獎勵和心得都存在瀏覽器的 localStorage，只留在該裝置，不會上傳；心得可以從心得本「匯出」成文字檔備份。
- 表格依共修說明排列，App 裡實際的段數如果不同，以 App 為準。
- 配色沿用「好好呼吸」的淺色主題（目前只留淺色；其他主題的背景圖還在 `assets/`，之後可以加回來）。
- 每 7 天算一週，共 9 週；聽完一週的早、午、晚會蓋一個印章，全部聽完再蓋「圓滿」。印章冊在右上角的選單裡，點印章可以寫下聽完後要給自己的獎勵。
- 重聽排程是選項，預設不開：首頁進度卡裡的「開始重聽」選日期後，每天排一天份，清單會標出重聽日期和「今天」；也可以勾「顯示共修日期」標出原本的日期。
- 每天的心得：點清單裡的「第01天」就能寫；右上角選單的「心得本」列出全部心得。
- 加到手機桌面：右上角選單有步驟說明；`manifest.webmanifest` 和 `icons/` 是桌面圖示用的。
